Ce vei învăța

  • Conceptele web pe care orice web developer trebuie să le știe
  • Cum să îți creezi propriile pagini și aplicații web
  • Cum să reproduci orice parte a unei pagini web
  • Poți decide dacă vrei să devii Developer sau preferi alte limbaje de programare

Cerințe

Nu ai nevoie de experiență în programare. Vei învăța pas cu pas tot ce îți trebuie.

Descriere

Vom învăța conceptele de bază de html & css de care avem nevoie, vom descoperi cele mai importante părți din web development și vom înțelege cum funcționează și de ce se comportă așa. După asta vom fi capabili să reproducem orice parte a unei pagini web.

Îți voi explica layout-uri css (css layout, flexbox, grid layout), ca să poți organiza și crea orice layout sau schelet de pagină. Și dacă vrei să înțelegi mai bine ce sunt selectorii css - vom atinge și acest subiect.

Vei construi 2 proiecte, în care vei aplica ce învățăm în curs.

Construim pas cu pas ambele proiecte, iar tu poți scrie codul odată cu mine și vezi rezultatele.

JavaScript pur este esențial, așa că vom lua mai mult timp să înțelegem cum funcționează JS și care sunt conceptele cheie ale acestui limbaj. Îți explic toate conceptele JS de care ai nevoie ca să poți începe orice proiect web și să înțelegi codul altora pe viitor. Lucrul cu date și crearea de fluxuri în aplicații vor fi o parte importantă a cursului.

Te învăț să folosești VSCode ca editor și să îți salvezi codul pe GitHub. Vom folosi comenzile git de bază pe care orice programator ar trebui să le știe.

Dacă ești Backend developer și vrei să înveți să îți creezi propriile interfețe web, cursul acesta te poate ajuta!

Câteva concepte JavaScript pe care le vom atinge:

  • Array helpers, JSON, DOM, Events, callback, Promises, pure functions

Pentru cine este cursul:

  • Pentru cei care vor să devină web developeri, dar nu doar atât - vom învăța și bazele programării
  • Dacă nu te-ai hotărât încă dacă vrei să mergi la cursuri live sau chiar la facultate, cursul acesta te poate ajuta.
  • Dacă programezi deja în Java/C# și vrei să înveți Web, cursul acesta te va ajuta să crești.
